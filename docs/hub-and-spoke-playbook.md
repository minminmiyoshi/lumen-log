# lumen-log ハブ&スポーク運用テンプレ（X / note）

作成: 2026-07-14 / 目的: 毎日の発信負荷を1mmも増やさずに、X・note の露出を lumen-log（母艦）に流し込み、軸「シフト勤務者の産業保健」へ評価を集約する。

前提（CLAUDE.md §1 と一致）: **X=日次速報／note=構造化考察・非医療読者の入口／lumen-log=残る情報・検索・一次情報**。

---

## 0. モデル（役割を固定して迷いを消す）

```
        [ X ]  日次速報・リアルタイム      ┐
                                          ├─► 全部 lumen-log（母艦）へリンクで着地
        [ note ] 物語・非医療読者の入口   ┘
                         │
                    lumen-log
              （記事＝資産／n=1データ／秋の産業医レイヤー）
```

**鉄則3つ（これだけ守る）**
1. 母艦は lumen-log。X/note に長文の"結論"を書き切らない。核心は母艦に置き、スポークは「入口＋リンク」。
2. プロフィールの外部リンクは **lumen-log 1本**に集約（linktree 等を挟まない）。
3. 毎日の速報スタイルは今のまま。**新規負荷は「週1回、母艦へ1本昇格」だけ**。

---

## 1. 最初の1回だけ：プロフィール整備（今日15分）

**X bio（末尾に固定）**
```
夜勤ER医／交代勤務者の産業保健を実測で研究。夜勤の科学と自分のn=1データ →
lumen-log.com
```
- 固定ポスト（ピン留め）に「夜勤の科学まとめ」= `https://lumen-log.com/health` を1つ。

**note プロフィール**
```
救急医。夜勤という働き方を科学と実測で最適化する記録。
一次情報・データは → lumen-log.com
連載小説「Lumen」もこちらから。
```

→ これで X も note も、辿ると必ず母艦に着く「漏斗の口」になる。

---

## 2. 記事を1本公開したとき：1記事→3面展開テンプレ（穴埋めコピペ）

lumen-log に記事を出したら、下を埋めて X と note に流すだけ。**考えるのは {核心データ1つ} と {意外な事実1つ} の2つだけ**。

### ▶ X（スレッド／速報の顔）
```
{記事の一番おもしろい事実を断言で}。

夜勤明けの{テーマ}について、{核心データ1つ}を実測して記事にした。

つづき（機序＋実践＋参考文献）はこちら↓
https://lumen-log.com/health/blog/{slug}
```
- 2ポスト目（任意・伸ばすとき）: `{意外な事実1つ}。ここは通説と逆だった。`
- **画像**: 記事の図（NightShiftChart）を1枚スクショで貼るとクリック率が上がる。

### ▶ note（非医療読者の入口・物語寄り）
```
（タイトル）{テーマ}を、夜勤明けの自分の身体で確かめてみた話

（本文200〜400字で"人の話"として導入。データや機序には深入りしない）
{なぜ気になったか}／{やってみて何が変わったか}を一人称で。

——機序・データ・参考文献など「ちゃんとした話」は、本サイトにまとめています。
▶ 続きを読む: https://lumen-log.com/health/blog/{slug}
```
- note は「感情と物語」、lumen-log は「エビデンス」。役割を混ぜない＝二重に書かなくて済む。

### ▶ lumen-log（母艦・本体）
- ここが結論の置き場。X/note からの着地点。記事末は自動で関連記事→シェアが付く（手書きしない）。

---

## 3. 日次運用（負荷ゼロ側：今のまま）

- **X の日次速報はそのまま続ける**。夜勤の一言、当直の気づき、データの断片 — これは"素材"。
- 素材のうち反応が良かった/半年後も価値がありそうなものだけ、**週1で母艦の1記事に昇格**（掲載基準＝CLAUDE.md「半年後も価値／一次情報／検索需要」）。
- つまり運用は「毎日は撒く・週1で母艦に定着させる」。日々の負荷は増えない。

---

## 4. 逆流導線（母艦→スポーク、スポーク→母艦）

- **母艦→X/note**: 記事末シェアボタンは既設（触らない）。
- **X/note→母艦**: 上のテンプレのリンクで担保。加えて X 固定ポスト＝`/health`、note プロフィール＝`lumen-log.com`。
- **秋の産業医レイヤー**: 記事が貯まったら、X bio と note プロフィールに1行 `産業医サービス（2026秋）→ /sangyoi` を足すだけで営業導線に転生（今はまだ足さない＝入口で隠す方針）。

---

## 5. 効いてるか見る最小指標（月1回・5分）

- lumen-log の流入元（X / note / 検索）のざっくり比率。検索が増えていれば母艦化が効いている。
- どの記事に外部リンクが集まるか＝次に厚く書くテーマの needs データ。
- 深追いしない。「検索流入が伸びているか」だけ見れば方向は分かる。
